# 浮序 2.2.0 M3 设计

| 项 | 内容 |
| --- | --- |
| 版本 | 2.2.0 |
| 范围 | 导入导出、运行记录、像素颜色条件 |

## 导入导出

单作业 JSON 与设计文档 `format: 1` 一致，可含 `scheduleStart` / `scheduleEnd` 与步骤可选 `color`。多作业导出为：

```json
{ "format": 1, "jobs": [ { ... }, { ... } ] }
```

## 运行记录

Room 表 `runs`，每次 `stopRun` 写一条，保留最近 100 条。

## 颜色条件

步骤可选 `ColorCondition`（坐标默认该步点击点、样本 ARGB、容差、不匹配跳过/停止）。运行前需 `MediaProjection`；读不到像素则停止并提示。
