# 浮序 Floatap

在用户自己的安卓设备上，用悬浮层选定位置，按间隔、定时或顺序循环执行点击。桌面端在安卓端成熟后再做。

本仓库当前阶段是产品与设计文档，还没有应用代码。

## 版本切片

1. **M0** 文档与仓库（当前）
2. **M1** 安卓单点连点：悬浮球、选点、固定间隔、运行时长后停止
3. **M2** 定时、随机间隔、顺序循环作业
4. **M3** 像素颜色条件（图像识别之前的可判定条件）
5. **M4** 局部画面匹配与简单条件脚本（规划项）
6. **M5** Windows 桌面端，复用同一套脚本格式

## 使用边界

浮序只在用户已授权的本机上，通过系统悬浮窗和辅助功能执行用户配置的点击。使用者需自行遵守应用商店、游戏、票务平台的规则以及当地法律。

不在产品范围内的能力：注入其他进程、root 提权、隐藏进程、对抗反作弊或安全软件、验证码破解、批量账号或代抢服务。
