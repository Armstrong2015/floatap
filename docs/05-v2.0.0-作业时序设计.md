# 浮序 2.0.0 作业时序设计

| 项 | 内容 |
| --- | --- |
| 版本 | 2.0.0 |
| 状态 | 已正式发布 |
| 不包含 | 定时开始、结束时刻、颜色条件、画面匹配、导入导出 |

## 1. 这一版做什么

1.1.2 的一份作业只有一个点，按同一个间隔重复点击。2.0.0 在此之上增加作业时序：把若干个这样的单点点击按顺序排成一轮，每一步有自己的等待，一轮走完再从头循环。

只有一步、不填循环次数的作业，行为和 1.1.2 相同。已保存的旧作业不用迁移。

## 2. 时序怎么理解

一份作业是有顺序的步骤列表，外加整份作业共用的停止条件。

一步就是一次单击，字段与单点作业相同：

| 字段 | 含义 |
| --- | --- |
| 顺序 | 从 0 起，界面显示为第 1 步、第 2 步 |
| 名称 | 便于辨认，默认「点击」 |
| 坐标和屏幕 | 选点时记下的 x、y、宽、高、方向 |
| 等待 | 固定毫秒，或最小到最大之间随机。规则与 1.1 相同：50 毫秒到 1 小时，最大不能小于最小 |

执行时不把多份作业拼在一起，只跑当前这一份里的步骤。

## 3. 一轮怎么走

从第 1 步到最后一步。每一步先等待，再检查停止条件，然后点击该步坐标。点完进入下一步。最后一步点完，循环次数加一，回到第 1 步。

等待用该步自己的间隔，发生在**该步点击之前**。因此步骤之间的间隔 = 下一步的「点击前等待」：第 1 步点完后，先按第 2 步的等待再点第 2 步；一轮最后一步点完后，先按第 1 步的等待再点第 1 步。随机等待只影响这一步下一次点击前的取值。

点击次数按整份作业累计，不是每步各自计数。持续时长从第一次点击开始算。

## 4. 怎样停

满足任一条件就停：

| 条件 | 界面 |
| --- | --- |
| 循环次数 | 填写 1 到 9999。走完这么多轮后停止，结束原因是循环完成 |
| 点击次数 | 可留空。累计点击达到次数后停止 |
| 持续时长 | 可留空。从第一次点击起算 |
| 用户停止 | 悬浮球菜单或通知里的停止 |

循环次数留空表示不限轮数。这时必须填写持续时长或点击次数，避免停不下来。填了循环次数以后，持续时长和点击次数可以留空。

循环次数填 0 或大于 9999，保存时拒绝。

某一步没有坐标时不能开始。准备选点时允许先记下还没选的步骤。

## 5. 配置和选点

编辑页在名称下面列出步骤。每一步可以改名称、间隔、随机间隔，并单独选点。可以添加步骤、上移、下移。至少保留一步，最后一步不能删。

选点：先打开要点的应用，再在编辑页点「选点」。浮序先保存并收起，直接盖上选点层，无需再开圆点菜单。点一下即写入当前步骤并回到编辑页；「取消选点」同样回编辑页。坐标只更新这一步。从圆点菜单选点时，写入最近一次在编辑页指定的步骤；没有指定过就写第 1 步，因此单点作业和 1.1.2 一样。

换一份作业时，圆点选点回到第 1 步。

## 6. 运行时界面

悬浮球的颜色、暂停、停止、点空白处收起菜单，与 1.1.2 相同。自动点击不会收起暂停菜单。

通知在点击后写明已点击次数。日志每一拍记下步骤序号、坐标和等待毫秒，便于核对顺序。

屏幕宽高或方向与该步标定时不一致，停止并提示重新选点。只检查当前要点击的那一步。

## 7. 明确不做

定时开始、每天的时间段、颜色判断、找图、滑动和长按都不在 2.0.0。步骤的动作只有单击。
