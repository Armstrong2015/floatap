# 浮序 Windows 桌面端设计（M5）

| 项 | 内容 |
| --- | --- |
| 版本 | windows-1.0.3 |
| 状态 | 已正式发布 |
| 对应安卓 | 能力对标 2.0.0 作业时序，共用 `format: 1` JSON |

## 1. 做什么

在 Windows 上选定屏幕坐标，按步骤等待与顺序循环点击。作业文件与安卓设计文档中的脚本 JSON 同结构，可手工复制。

## 2. 怎么点

使用 Win32 `SendInput` 发送绝对坐标的鼠标左键按下与抬起。坐标为屏幕物理像素；进程启用 Per-Monitor DPI 感知，选点层与点击使用同一坐标系。

## 3. 界面

- 主窗口：引导、作业列表、编辑（多步、等待、循环 / 时长 / 次数、倒计时）
- 全屏选点层：半透明置顶，点一下记下坐标并回到编辑页；可取消
- 置顶悬浮球：空闲菜单含作业、选点、开始、打开；运行中暂停 / 停止

## 4. 运行语义

与安卓一致：每步先等待再点击；停止条件在点击前检查；暂停后继续时从当前步重新等待。

控制：

- 主窗口底部 **暂停 / 继续**、**停止** 按钮
- 运行时置顶控制条同样可点暂停、停止
- **F8** 暂停/继续，**F9** 停止（轮询按键，不装钩子）
- 程序 `SendInput` 点击后把光标设回点击前位置，避免抢走鼠标
- 落点闪圈提示

可选「运行中用户按下鼠标左键则暂停」用 `GetAsyncKeyState` 轮询；**不安装**全局低级鼠标钩子。

## 5. 存储

`%APPDATA%\Floatap\jobs\*.json` 与 `prefs.json`。不申请网络。

## 6. 不做

定时开始、颜色 / 画面匹配、注入、绕过 UAC、对抗反作弊。对需要管理员权限的窗口，普通权限下的点击可能无效，需用户自行以合适权限运行目标程序或浮序。
