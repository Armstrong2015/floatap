# 浮序 2.1.0 定时开始

| 项 | 内容 |
| --- | --- |
| 版本 | 2.1.0 |
| 状态 | 已正式发布 |
| 对应需求 | FR-13 开始时刻、FR-14 结束时刻、FR-15 等待期间可停 |

## 字段

继续使用作业上的 `scheduleStartMinutes` / `scheduleEndMinutes`（当天 0 点起的分钟，0–1439，`null` 表示未设置）。

## 运行

1. 用户点开始 → `ARMED`
2. 若设了开始时刻且未到：通知「等待 HH:MM」，前台服务 + 精确闹钟分段等待；用户可停
3. 到点后走原有倒计时 → `RUNNING`
4. 每次点击前若结束时刻已到 → `SCHEDULE_END`

开始时刻相对「今天」已过：编辑页弹窗；悬浮球则改为立即开始。仅结束且已过：拒绝开始。不跨天、不开机自启。
