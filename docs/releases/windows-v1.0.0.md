# 浮序 Windows 1.0.0

Windows 桌面端第一版正式包，能力对标安卓 2.0.0 的作业时序。

安装包：[floatap-windows-1.0.0.exe](https://github.com/Armstrong2015/floatap/releases/download/v-windows-1.0.0/floatap-windows-1.0.0.exe)

下载后直接运行，无需安装。作业保存在本机 `%APPDATA%\Floatap`。

## 这一版能做什么

- 新建作业，添加多个步骤，每步单独选点
- 每步设置点击前等待（固定或随机）
- 按顺序循环；可设循环次数、持续时长或点击次数
- 开始倒计时；悬浮球开始 / 暂停 / 停止
- 选点后自动回到编辑页

## 怎么用

1. 运行 `floatap-windows-1.0.0.exe`，阅读使用边界后进入作业列表。
2. 新建作业，先打开要点的窗口，再在对应步骤点「选点」，点一下目标位置。
3. 填好等待与停止条件，保存。
4. 点悬浮球「开始」，或在列表里点「开始」。

## 说明

- 与安卓安装包相互独立，签名与版本号不混用。
- 作业 JSON 字段与安卓 `format: 1` 一致，可手工复制文件。
- 不做注入、不绕过系统权限、不对抗反作弊。
