# 浮序 2.1.0

2.1.0 增加定时开始与结束时刻。安装包待实机确认后再挂到正式 Release。

## 本版

- **定时开始**：可选。点开始后进入等待，到设定的本地时刻再倒计时并点击
- **结束时刻**：可选。到达该本地时刻后停止（结束原因：到达结束时刻）
- 开始时刻已过：编辑页询问「立即开始 / 取消」；悬浮球开始则提示并改为立即开始
- 仅结束时刻已过：拒绝开始，请先改时间
- 不限循环时，持续时长、点击次数、结束时刻三者至少填一

定时只针对「今天」；不做开机自启，也不静默等到第二天。

## 怎么用

1. 编辑作业，打开「定时开始」和/或「结束时刻」，填写时、分。
2. 保存后点开始（或从悬浮球开始）。
3. 等待期间通知会写「等待 HH:MM 开始」；可随时停止。
