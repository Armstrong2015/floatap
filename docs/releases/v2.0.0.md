# 浮序 2.0.0

2.0.0 是作业时序大版本：一份作业可以排多个点击步骤，按顺序循环；单点作业仍与 1.1.2 相同。

安装包：[floatap-2.0.0.apk](https://github.com/Armstrong2015/floatap/releases/download/v2.0.0/floatap-2.0.0.apk)

签名与 1.x 正式包相同，可直接覆盖安装。装好后如系统清过权限，再打开悬浮窗和辅助功能。

## 这一版能做什么

- 保留 1.1.2 的单点连点、固定或随机间隔、倒计时、按时长或次数停止
- 一份作业可添加多步，每步单独选点、单独设置点击前等待
- 按第 1 步 → 最后一步的顺序点击，一轮结束后从头循环
- 可填写循环次数（1–9999）；不限轮数时须填写持续时长或点击次数
- 配置页点「选点」：先打开目标应用，再点选点，直接进入选点层，点一下即回配置页
- 「取消选点」同样回到配置页；再点悬浮球可收起菜单

定时开始、颜色条件、画面匹配不在这一版。

## 步骤等待怎么理解

每一步的等待发生在**该步点击之前**。上一步点完后，先按下一步的「点击前等待」再点下一步；一轮最后一步点完后，先按第 1 步的等待再点第 1 步。

## 选点

1. 先打开要点的应用，把目标留在画面上。
2. 回到浮序，打开作业，在对应步骤点「选点」。
3. 浮序收起并盖上选点层，点一下要记的位置。
4. 自动回到配置页，该步坐标已更新。

也可从圆点菜单里选点；写入的是最近一次在编辑页指定的步骤，没有指定过则写第 1 步。

## 和 1.1.2 的差别

| | 1.1.2 | 2.0.0 |
| --- | --- | --- |
| 点击点 | 每份作业一个点 | 可多步顺序 |
| 等待 | 整份作业一个间隔 | 每步各自的点击前等待 |
| 循环 | 按间隔重复同一点 | 可设循环次数，或仍用时长 / 点击次数 |
| 选点回页 | 需自行回到应用 | 选完或取消自动回配置页 |
