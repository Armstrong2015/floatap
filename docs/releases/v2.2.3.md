# 浮序 2.2.3

2.2.3 提供作业导入导出与本机运行记录（M3）。像素取色已撤销，画面匹配留到 M4。

安装包：[floatap-2.2.3.apk](https://github.com/Armstrong2015/floatap/releases/download/v2.2.3/floatap-2.2.3.apk)

## 本版

- **导出**：可勾选一份或多份作业（也可全选）写成 JSON（`format: 1`）
- **导入**：文件内全部作业写入本机；若与现有作业同名，自动加数字后缀（如 `每日` → `每日2`）
- **运行记录**：首页「记录」查看本机最近约 100 次结束原因与点击次数（仅本地，不上传）

## 怎么用

1. 首页点「导出」，勾选要分享的作业，保存 JSON。
2. 另一台手机点「导入」，选中该文件即可。
3. 点「记录」查看近期运行结果。

装过更早正式包可直接覆盖安装；若曾装调试签名包，需先卸载再装。装好后重新打开悬浮窗和辅助功能。
