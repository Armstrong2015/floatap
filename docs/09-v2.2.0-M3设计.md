## 导入导出

单作业 JSON 与设计文档 `format: 1` 一致。多作业导出为：

```json
{ "format": 1, "jobs": [ { ... }, { ... } ] }
```

便于用户分享配置。导出时可勾选若干份（含全选）。导入文件内全部作业；与本机同名时自动加数字后缀（如 `每日` → `每日2`）。导入后超过 50 份则拒绝。
